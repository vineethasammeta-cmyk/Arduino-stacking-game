# Arduino-stacking-game
Description
A row of LEDs lights up in a stacking motion. When the player presses a button, the currently illuminated LED is captured. The player advances to the next level if the captured LED aligns directly above the previously captured row.

Components Used:
-Arduino UNO R3 with cable 
-MAX7219 Dot LED 8*32 matrix 
-Pushbutton
-Jumper wires & Breadboard 
-Plastic box for casing
